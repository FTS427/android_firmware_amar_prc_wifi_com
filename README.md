# Origin firmware for Lenovo TB-X306FC

- SoC: MT8768WT (or MT6765)
- GPU: PowerVR Rogue GE8320
- Display: 800x1280 60Hz
- RAM: 4GB
- Storage: 64GB
- NFC: No support
- Origin ROM: Android 11 with Lenovo customized
> It seems that the really original ROM is Android 10, but this device actually running this Android 11 after I open the package
- Project Treble: Support
- Dynamic patitions: Yes
- Kernel: the original one is 4.19.127, and I updated it to 4.19.325 (the latest ACK 4.19 ASB)
- WiFi: Support 5GHz but don't support the 6GHz
- Front Camera: 5MP
- Rear Camera: 8MP
